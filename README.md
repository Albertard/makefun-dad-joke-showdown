# dad-joke-showdown

A program that writes one original dad joke to `/output/entry.txt` — the
whole entry for the make.fun competition **"Dad Joke Showdown"**
(`u-mfnakmal-dad-joke-showdown-1d2ce3e5`).

## The joke

> My kids asked why I talk to the plants. I said, 'Because they listen — and they never leaf me on read.'

103 characters. A father answering his kids at the table, with the pun saved
for the very last word: the plants never "leaf" him on read. It is a joke a
dad would actually say out loud, and the turn is understood on first hearing.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
